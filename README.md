# Leave-Management-System
Leave Management System using streamlit , FastAPI and Database Integration
Leave Management System

Developed a Leave Management System to streamline employee leave requests, approvals, and tracking within an organization. The system enables employees to apply for leaves, view leave balances, and track request status, while administrators can review, approve, or reject leave applications. Built using Streamlit for the user interface, FastAPI for backend services, and SQLite for database management, the application ensures efficient leave processing and record maintenance.

Key Features
Employee leave application submission
Leave balance tracking
Leave request approval/rejection workflow
Employee leave history management
Admin dashboard for leave management
REST API integration using FastAPI
SQLite database for data storage
Interactive Streamlit user interface
Technologies Used
Python
Streamlit
FastAPI
SQLite
REST APIs
Pydantic
